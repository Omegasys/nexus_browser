# Nexus Browser Documentation

Welcome to the Nexus Browser documentation.

Nexus Browser is a GPLv3 open-source modular browser platform focused on:

* Privacy
* Security
* Engine flexibility
* User control
* Network freedom
* Research and experimentation

The goal of Nexus is to create a browser architecture that combines:

* Tor-level anonymity concepts
* Strong fingerprint resistance
* Qubes-style isolation
* Firefox-style extensibility
* Vivaldi-style customization
* Modular rendering and JavaScript engines
* Advanced network routing control
