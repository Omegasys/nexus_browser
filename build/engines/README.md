# Nexus Browser Engine Build Output

This directory contains generated build output for Nexus Browser engines.

Engine source code belongs under:

engines/

Generated engine artifacts may include:

- Rendering engine binaries
- JavaScript engine binaries
- Networking engine binaries
- DNS engine binaries
- Storage engine binaries
- Graphics engine binaries
- Security engine binaries
- Engine adapters
- Shared libraries
- WebAssembly engine modules
- Engine manifests generated during the build process

This directory is generated by the Nexus Browser build system.

Do not place primary engine source code here.

Typical build flow:

engines/
    ↓
engine_compiler
    ↓
engine_builder
    ↓
build/engines/
    ↓
engine_validator
    ↓
build/artifacts/
